## High

### H1 — Updater HTTP downgrade possible (no `.https_only(true)`)
- `src/utils/updater.rs:59` — `check_for_updates()` Client::builder lacks `https_only(true)`. URL is hardcoded `https://api.github.com/...` but reqwest will follow `http://` redirects from compromised proxy/DNS, allowing MITM injection of malicious release JSON.
- `src/utils/updater.rs:154` — `download_update()` same gap. Host allowlist enforced, scheme not.
- Fix: add `.https_only(true)` to both `Client::builder()` calls.

### H2 — `expect()` on global `AudioPlayer` (panic if init order wrong)
- `src/utils/daemon.rs:39` — `get_audio_player().expect(...)` panics on access before init. CQ-02 in old queue, still open.
- Fix: return `Option<_>` or guard with `try_get_audio_player`; map None to typed error in caller.

## Medium

### M1 — VB-Cable zip extraction TOCTOU
- `src/utils/vbcable_install.rs:140-141` — `create_dir_all(parent)` runs before canonical-path containment check. Symlink planted between mkdir and check could escape extraction root.
- Fix: validate canonical parent + symlink-free path BEFORE `create_dir_all`.

### M2 — IPC slow-loris (silent timeout)
- `src/utils/daemon_run.rs:119` — read timeout error logged but not closed; connection lingers consuming task slot.
- Fix: return early on timeout, drop stream.

### M3 — Auto-tag/release workflow advertises non-existent Linux artifact
- `.github/workflows/auto-tag.yml:35` — release-notes disclaimer mentions `soundboard-Linux.zip`. v1.10 dropped Linux. Misleads downloaders.
- Fix: edit disclaimer to Windows only.

### M4 — Release workflow lacks pre-publish gate
- `.github/workflows/release-windows.yml:84` — packages binary without running `cargo test` / `cargo clippy -D warnings` / `cargo fmt --check` first.
- Fix: add gate steps before zip step. CI workflow already has them — duplicate or use `needs: [ci]`.

### M5 — Dependabot auto-merge does not require CI green
- `.github/workflows/dependabot-auto-merge.yml:21` — `gh pr merge --auto --squash` without verifying mergeable_state or `needs: [ci]`. CI failure + auto-merge can land broken patch. (Patch-only restriction limits blast radius but does not eliminate.)
- Fix: add `if: github.event.pull_request.mergeable_state == 'clean'` or gate on workflow `needs:`.

### M6 — `unwrap_or_default()` on `PlayerState` JSON decode (silent state corruption)
- `src/utils/gui.rs:177` — malformed daemon response → silent fallback to `Stopped`. UI desync, no log.
- Fix: log parse error at warn before defaulting; suggests protocol drift.

### M7 — Runtime size compute overflow (192 kHz × 1024 ch hypothetical)
- `src/types/audio_player.rs:536` — `sample_rate_hz as usize * channels as usize` unchecked.
- Fix: `checked_mul()` with safe fallback ring size.

### M8 — Mic-passthrough thread leaked on `AudioPlayer` drop
- `src/types/audio_player.rs:542` — `thread::spawn` not joined; mic stream thread outlives producer.
- Fix: store `JoinHandle` in `AudioPlayer`, join on Drop.

### M9 — Hotkey thread no shutdown signal
- `src/gui/hotkeys.rs:59-61` — infinite `recv()` blocks until process exit. Hotload restart leaks thread.
- Fix: bounded `recv_timeout` or oneshot stop channel.

### M10 — Audio thread blocking I/O
- `src/types/audio_player.rs:615-620` — `File::open` + `Decoder::try_from` runs synchronously in `play_on_layer()`. Caller may be on tokio runtime / GUI tick thread; large file → audio glitch.
- Fix: pre-buffer or `spawn_blocking`.

### M11 — Mutex held across long sleep
- `src/utils/daemon_run.rs:194` — `get_audio_player().lock().await` held during `sleep`. Blocks other handlers.
- Fix: clone state needed, drop guard, then sleep.

### M12 — Zero GUI tests, zero glue tests, no integration suite
- `src/gui/*` (8 files), `src/utils/{daemon,daemon_run,gui,cli_run}.rs`, `src/types/{commands,gui}.rs` — no `#[test]`. No `tests/` dir. No coverage tool.
- Fix: add `tests/ipc_smoke.rs` round-trip test (spawn `--headless`, open TCP, run command). Add `tests/updater_verify.rs` with mock server. Cover `commands.rs` parse/exec at minimum.
